# IMDB Top 1000 Movies - Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the IMDB Top 1000 Movies dataset.
The analysis explores patterns in movie ratings, genres, runtime, revenue, and audience engagement to uncover insights about successful films.

## Dataset
IMDB Top 1000 movies dataset containing ratings, votes, runtime, gross revenue, etc.

## Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Plotly

## Key Questions
- Which genres dominate the IMDB Top 1000?
- Which movies have the highest ratings?
- Do higher revenue movies receive more votes?
- How does runtime relate to ratings?

## Key Insights
- Drama is the most common genre.
- Movies earning higher gross revenue receive more audience votes.
- Runtime mostly ranges between 100–140 minutes.
- Ratings generally fall between 7.5 and 8.5.
